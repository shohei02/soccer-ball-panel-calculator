# Soccer Ball Panel Calculator

正五角形12枚と正六角形20枚からなる切頂二十面体を、  
板材から製作するための寸法を計算するWebアプリケーション。

## Features

- 板厚に応じた加工可否の判定
- 正五角形・正六角形の板材寸法の計算
- 側面の加工角度・削り込み量の計算
- 組立時の最大外径・削り出せる最大球径の計算

## Usage

`index.html` をブラウザで開き、一辺の長さと必要に応じて板厚を入力する。  
入力内容に応じて、各寸法と板厚の判定結果が自動で更新される。

インストールやビルドは不要。

## Testing

Node.jsで計算ロジックのテストを実行できる。

```bash
node test/calculator.test.js
```
